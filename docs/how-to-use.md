# 基本操作・AI校正の使い方

## メモを書く

`Alt + Space` でウィンドウを開き、文章を入力してください。`Ctrl + Alt + Enter` を押すと、全文をコピーして元のアプリに戻ります。文章の一部を選択している場合は、その部分だけをコピーします。

本文は自動で保存されます。ウィンドウを閉じてもアプリはタスクトレイに残り、次に開いたときも続きを書くことができます。アプリを終了する場合は、タスクトレイのアイコンを右クリックして「終了」を選んでください。

設定は、ウィンドウ上部の設定ボタンか、タスクトレイの右クリックメニューから開きます。文字の大きさは「エディタ」、テーマや呼び出しキー、ウィンドウの位置は「全般」で変更できます。

よく使うキーは以下のとおりです。「表示・非表示」と「コピーして隠す」のキーは、設定で変更できます。

| 操作 | キー |
|---|---|
| 表示・非表示 | `Alt + Space` |
| コピーして隠す | `Ctrl + Alt + Enter` |
| タブを追加 | `Ctrl + T` |
| タブを閉じる | `Ctrl + W` |
| 閉じたタブを戻す | `Ctrl + Shift + T` |
| 検索 / 置換 | `Ctrl + F` / `Ctrl + H` |
| 全タブから検索 | `Ctrl + Shift + F` |
| 今のタブをファイルに書き出す | `Ctrl + Shift + S` |

## APIキーを設定する

APIキーは、使用するモデルの提供元で発行してください。Google、OpenAI、Anthropic、Preferred NetworksとOpenAI API互換の接続先に対応しています。サブスクを使用する場合は、[契約サービスの設定](subscription-backends.md)を参照してください。

1. 設定の「APIキー」を開き、「API の提供元」を選んでください。
2. 「キーの取得元」で「アプリに保存したキー」を選び、「APIキーを入力」にキーを貼り付けてください。
3. 「校正」を開き、自動校正と手動校正で使用するモデルをそれぞれ選んでください。同じモデルでも構いません。
4. 「料金」で「月間上限額（USD）」と「課金API実行前の確認を表示する」を確認し、「保存して閉じる」を押してください。

自動用と手動用で別の提供元を選んだ場合は、それぞれの接続先で必要なAPIキーを設定してください。キー不要のOpenAI API互換接続先では空欄にできます。キーを変更しない場合は、入力欄を空欄にしておくと保存済みのキーをそのまま使います。

新規設定の自動用・手動用モデルは、[比較計測の結果](../PromptValidation/reports/model-benchmark-2026-09-23.md)に基づきどちらも GPT 6 Luna です。保存済みのモデル選択は変更しません。

### OpenAI API互換の接続先


設定の「APIキー」→「OpenAI API互換」で接続先を追加できます。プリセットはありません。接続先ごとに表示名、`/chat/completions` までを含む完全なURL、APIのモデルID、入力・出力それぞれのUSD単価（100万トークン当たり）を入力します。APIキーが必要なら同じ画面で登録します。登録した接続先は「校正」の自動用・手動用で別々に選べます。キーを使わないローカルサーバーなら空欄にできます。

互換接続は Chat Completions 形式を使用し、モデル固有の思考量パラメータは送りません。応答の停止理由が `stop` 以外なら校正結果を採用しません。接続先がトークン使用量を返さない場合、料金は0円とせず「未確認」と表示します。

入力した単価を全入力トークンに適用し、**キャッシュ料金は計算しません**。キャッシュ読み込み割引が適用された場合、アプリの表示額は実際の請求額より高めになります。キャッシュ書き込み割増、追加料金、単価変更、独自の課金方式は計算に含まれず、表示額は請求額の上限ではありません。実際の料金は接続先で確認してください。HTTPの接続先では本文とAPIキーが通信中に暗号化されません。

環境変数にキーを設定している場合は、「キーの取得元」で環境変数を選ぶこともできます。使われる変数は以下のとおりです。起動中のアプリに反映されない場合は、タスクトレイから終了して起動し直してください。

| 提供元 | 環境変数 |
|---|---|
| Google | `GEMINI_API_KEY` |
| OpenAI | `OPENAI_API_KEY` |
| Anthropic | `ANTHROPIC_API_KEY` |
| Preferred Networks | `PLAMO_API_KEY` |

## 文章を校正する

文章を書いて `Ctrl + Enter` を押すと、手動で校正できます。一部を選択してから押すと、その範囲を校正します。APIキーを使う場合は料金が発生し、サブスクを使う場合は利用枠を消費します。

修正案が見つかると、本文と下部のパネルに表示されます。修正箇所をクリックするか `F8` で選び、内容を見て「許可」か「拒否」を押してください。「すべて許可」でまとめて反映することもできます。

| 操作 | キー |
|---|---|
| 手動で校正 | `Ctrl + Enter` |
| 次の修正案 / 前の修正案 | `F8` / `Shift + F8` |
| 許可 | `Ctrl + .` |
| 拒否 | `Ctrl + ,` |
| すべて許可 | `Ctrl + Shift + .` |

自動校正は、設定の「校正」にある「入力停止後に自動で校正する」で切り替えます。APIキーを使う場合、初期設定では入力を止めて5秒後、前回の校正開始から10秒以上経っていれば、変更した段落を送信します。手動でだけ校正したい場合は、この設定をオフにしてください。

別案の生成には自動校正のモデル、文体のルールをまとめるスタイルガイドの生成には手動校正のモデルを使います。これらも、APIキーを使う場合は料金が発生し、サブスクを使う場合は利用枠を消費します。

## AIに送る内容

校正では、対象の段落と、その前後1段落を文脈として送信します。選択範囲を校正するときも、前後の文章を文脈として送ります。長い文章は分割して送信するため、1回の校正で複数回通信することがあります。

過去の許可・拒否は文体に合わせた校正に使います。選ばれた履歴の原文・修正案・拒否理由、スタイルガイド、「学習」で入力したカスタム指示もAIへ送られます。スタイルガイドを生成するときは、蓄積したリアクション履歴を送ります。

外部に送りたくない文章は、校正をオフにしてメモ帳として使用してください。本文や履歴の保存場所は[こちら](data-and-support.md)に記載しています。

## 料金を確認する

APIの概算料金はウィンドウ下部に表示されます。`Ctrl + Shift + B` か、タスクトレイの「課金履歴」から明細を確認できます。既知モデルの単価や通貨は設定の「料金」、OpenAI API互換の単価は「APIキー」で変更できます。

APIの月間上限額は初期設定で2ドル、0にすると無制限です。上限に達すると自動校正が止まりますが、手動校正は引き続き実行できます。「課金API実行前の確認を表示する」をオフにしている場合は、上限到達後も確認なしで実行します。送信後に料金を計算するため、上限額を超えることもあります。この上限には、ほかのアプリで使用したAPI料金は含まれません。

表示額はアプリに登録された単価と為替レートから計算した概算です。キャッシュ入力の割引は計算しないため、割引が適用されると表示額は実際より高めになります。Claude APIのキャッシュ読み込み・書き込みトークンも通常の入力単価で計算します。キャッシュ書き込みの割増、追加料金、単価変更などで実際の請求額が上回る場合もあるため、請求額は提供元で確認してください。サブスクの使用分はAPI料金に換算せず、利用回数として記録します。
