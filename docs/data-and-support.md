# 保存場所・バックアップ・困ったとき

## データの保存場所

本文や設定は `%APPDATA%\JpScratch` に保存します。設定画面の「データフォルダを開く」から開くことができます。

| ファイル・フォルダー | 内容 |
|---|---|
| `tabs` | タブごとの本文。テキストファイルで保存します |
| `tabs\trash` | 閉じたタブの本文 |
| `settings.json` | アプリの設定 |
| `pricing.json` | 料金の計算に使う単価 |
| `app.db` | タブ情報、校正のリアクション、スタイルガイド、使用履歴など |
| `credentials.dat` | 暗号化して保存したAPIキー |
| `crash.log` | 異常終了時のログ |

閉じたタブは、初期設定では30日間ゴミ箱に残ります。`Ctrl + Shift + T` で戻すか、ウィンドウ上部のゴミ箱から選んで復元してください。完全削除したものはゴミ箱から戻せません。

アプリが起動しない場合も、`tabs` 内のテキストファイルはメモ帳などで読むことができます。本文は暗号化していません。

## バックアップを作る

1. 設定の「全般」を開いてください。設定を編集中の場合は、先に「保存して閉じる」で保存してから開き直してください。
2. 「保存・起動とサポート」から「サポート・バックアップ」を開き、「バックアップを作成」を押してください。
3. 保存先を選んでください。`.jpsbackup` ファイルが作成されます。

バックアップには本文、設定、データベース、保存済みのAPIキーが含まれます。本文や履歴も入るので、ファイルの共有先には注意してください。

APIキーはWindowsユーザーに結び付けて暗号化しています。別のPCやユーザーへ移した場合、キーを復号できないことがあるため、その場合は入力し直してください。環境変数のキーと、サブスクのログイン情報はバックアップに含まれません。

## バックアップを戻す

同じ画面の「バックアップから復元」でファイルを選び、内容を確認して復元してください。現在のデータを別のフォルダーへ退避してからバックアップに置き換え、アプリを再起動します。今のタブに追加されるわけではありません。

復元前のデータは、通常 `%APPDATA%` 内の `JpScratch.before-restore-日時-識別番号` というフォルダーに残ります。退避先は復元が終わったときにも表示します。

校正や別案の生成中は復元できません。処理が終わってから実行してください。本文を保存できないというエラーが出た場合は、保存先の空き容量とアクセス権を確認してください。

## ウィンドウが開かない

タスクトレイにアイコンがあれば、クリックして開いてください。表示されない場合は、通知領域の隠れているアイコンも確認してください。

アイコンからは開けるのに `Alt + Space` が効かない場合は、ほかのアプリとキーが重なっている可能性があります。設定の「全般」で呼び出しキーを変更してください。

通常版のインストーラーを使用し、起動時にランタイムを求められた場合は、.NET 10 Desktop Runtime（x64）が必要です。ランタイム同梱版を使うこともできます。[インストールの説明](../README.md#インストール)を参照してください。

## 校正できない

まずウィンドウ下部のメッセージを確認してください。APIキー未設定の場合は「APIキー」、サブスクの接続エラーの場合は「契約サービス」で設定を確認します。自動用と手動用で提供元が違う場合は、それぞれの設定が必要です。

手動では動くのに自動で動かない場合は、「入力停止後に自動で校正する」、月間上限額、待ち時間を確認してください。サブスクでは「自動校正で契約枠を使う」もオンにする必要があります。残量が不明な場合も自動校正は止まります。

タイムアウトが続く場合は、「校正」の「詳細設定：送信間隔・タイムアウト」で待ち時間を延ばすか、使用するモデルを変えてください。サブスクの接続については[こちら](subscription-backends.md#接続できないとき)も参照してください。

## 不具合を報告する

設定の「全般」→「保存・起動とサポート」→「サポート・バックアップ」にある「診断情報をコピー」を押してください。アプリのバージョンやOSなどがコピーされます。本文やAPIキーは含めません。

[GitHubのIssues](https://github.com/Ringoacid/jp-scratch/issues)に、診断情報、行った操作、期待した動作、実際に起きたことを書いてください。エラーメッセージや画像を添える場合は、本文やキーが写っていないか確認してください。
