# モデル仕様書: GPT-5.6 Luna

## 1. 概要

- **モデル名**: GPT-5.6 Luna
- **モデルID**: `gpt-5.6-luna`
- **プロバイダー**: OpenAI
- **API**: Responses API（`POST /v1/responses`）
- **位置付け**: コスト重視・大量利用向けの高速モデル
- **最終確認日**: 2026年7月31日

## 2. 入出力と上限

- **入力**: テキスト、画像
- **出力**: テキスト
- **コンテキストウィンドウ**: 1,050,000 tokens
- **最大出力**: 128,000 tokens
- **推論トークン**: 対応

## 3. JP Scratch での利用

- Gemini 3.5 Flash-Lite と同じ全文校正プロンプト、差分検査、理由付き別案生成の契約で利用する。
- システム指示は Responses API の `instructions`、校正本文は `input` に渡す。
- `reasoning.effort` は `low`、`store` は `false` とする。
- `output_text` を優先して校正結果を取得する。レスポンスの `usage` から入力、出力、推論、
  キャッシュ入力トークンを読み取り、共通の課金ログへ保存する。

## 4. 標準単価

OpenAI のモデルページで 2026年7月31日に確認した値。単位は 1M tokens あたりの USD。

| 区分 | 単価 |
|---|---:|
| 入力 | **$0.20** |
| キャッシュ入力 | **$0.02** |
| 出力 | **$1.20** |

公式: [GPT-5.6 Luna model page](https://developers.openai.com/api/docs/models/gpt-5.6-luna)

本アプリの `pricing.json` と設定画面は入力単価・出力単価の2項目を保持する。キャッシュ入力トークン数は
使用量として記録するが、キャッシュ専用単価の編集欄はまだ持たず、料金計算は入力・出力単価を使う。
